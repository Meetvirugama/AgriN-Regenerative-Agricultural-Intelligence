# Project Git Workflow Rule

For any modifications, features, fixes, or commits in this project:
1. **Always create a brand new branch** for the specific task before committing.
2. **Stage and commit changes only to that newly created branch**.
3. **Push the branch upstream** to `origin/<new-branch-name>` when requested.
4. **Never commit directly to existing or shared branches** unless explicitly instructed by the user.
